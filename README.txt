1. ОПИСАНИЕ ПРОЕКТА
--------------------------------------------------------------------------------
Данный репозиторий содержит полную production-ready конфигурацию многопользовательского
облачного сервера JupyterHub, развернутого на виртуальной машине Google Cloud Platform (GCP).

Сервер предназначен для студентов, коллег и аналитиков. Каждому пользователю выделяется
персональный изолированный Docker-контейнер с гарантированными лимитами ресурсов и
постоянным дисковым пространством.


2. КЛЮЧЕВЫЕ ВОЗМОЖНОСТИ И АРХИТЕКТУРА
--------------------------------------------------------------------------------
- Выбор рабочего профиля при запуске:
    1) Data Science: предустановлены Pandas, NumPy, Matplotlib, Seaborn, OpenPyXL, Requests.
    2) Чистый Python: легковесный Jupyter Minimal Notebook для базовых задач.

- Строгие аппаратные квоты (на один контейнер):
    * Оперативная память: Лимит 512MB, гарантия 256MB.
    * Процессор: Лимит 0.5 CPU, гарантия 0.2 CPU.
    * Предотвращает зависание сервера при запуске «тяжелых» циклов новичками.

- Трехуровневая система безопасности:
    * Закрытая регистрация (allow_all = False): учетные записи создает только Admin.
    * Сетевая изоляция: порт 8000 привязан только к 127.0.0.1 (локальный хост).
    * Ловушка для ботов в Nginx (код 444): прямые запросы по IP-адресу сбрасываются.
    * Cloudflare SSL: весь публичный трафик шифруется по HTTPS.
    * Idle Culler (автоусыпление): серверы без активности более 60 минут автоматически
      останавливаются, освобождая оперативную память. Файлы сохраняются на диске.

- Персистентное хранение:
    * Рабочие файлы монтируются из /opt/jupyterhub/data/{username} в /home/jovyan/work.


3. СТРУКТУРА ФАЙЛОВ В РЕПОЗИТОРИИ
--------------------------------------------------------------------------------
- docker-compose.yml       : Описание сервиса JupyterHub и монтирования томов.
- jupyterhub_config.py     : Главный конфигурационный файл (DockerSpawner, безопасность, профили, idle-culler).
- Dockerfile               : Сборка кастомного образа JupyterHub с аутентификацией и idle-culler.
- Dockerfile.datascience   : Сборка образа для Data Science со всеми библиотеками.
- nginx/jupyterhub.conf    : Конфигурация Nginx (проксирование, WebSocket, защита от прямого IP).
- deploy.sh                : Скрипт развертывания проекта «в один клик» на Ubuntu/Debian.
- .gitignore               : Исключение служебных баз данных SQLite и приватных файлов.
- README.txt               : Текущее текстовое руководство.
- README.md                : Подробная документация в формате Markdown для GitHub.


4. ИНСТРУКЦИЯ ПО АДМИНИСТРИРОВАНИЮ
--------------------------------------------------------------------------------
А) Добавление нового пользователя:
   1. Войдите на https://jupyter.customser.az под логином 'admin'.
   2. В верхнем меню нажмите вкладку 'Admin'.
   3. Нажмите кнопку 'Add Users'.
   4. Введите имя пользователя (например, 'student_01') и сохраните.
   5. Пользователь может открыть сайт, ввести свой логин и придумать пароль при первом входе.

Б) Изменение времени усыпления (Idle Timeout):
   В jupyterhub_config.py в блоке 'c.JupyterHub.services' измените флаг:
   --timeout=3600 (3600 сек = 1 час).
